Los 6 atajos más productivos en Excel 365 Windows

Empieza por estos y notarás la diferencia desde el primer día: Alt + = para Autosuma instantánea, Ctrl + 1 para abrir Formato de celdas, F4 para fijar referencias absolutas ($A$1), Ctrl + ` para ver todas las fórmulas, Ctrl + Fin para saltar al último dato y Ctrl + Alt + V para Pegado especial (solo valores). Todos verificados para Windows 10/11 con Excel 365 en español.
